# Path2Profit
This is a model comparison study on user behavior data to determine the best predictive model for e-commerce revenue generation, demonstrating how businesses can utilize ML to optimize strategy and target demographics.

One file includes the base data visualization and comparison, and other files implement feature engineering, model training, SMOTE, and hyperparameter tuning across several algorithms, including logistic regression, SVC, decision tree classifier, random forest classifier, XGB classifier, LGBM classifier, MLP classifier, and gradient boosting classifier.
